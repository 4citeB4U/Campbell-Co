# Campbell & Co. Jewelry Assets

This folder is the source of truth for storefront product and category imagery.

The attached page references in the planning conversation map to these filenames:

- `women-rings.png`
- `men-rings.png`
- `women-chains.png`
- `men-chains.png`
- `women-pendants.png`
- `men-pendants.png`
- `women-bracelets.png`
- `men-bracelets.png`
- `stud-earrings.png`
- `loose-diamonds.png`
- `diamond-macro.png`

Every product detail page uses the same image contract for its gallery, story, and passport experience. If a page image has multiple product crops, add them beside the page image using the product slug, for example:

- `women-pendants/solitaire-pendant.png`
- `women-pendants/halo-diamond-pendant.png`
- `men-bracelets/8mm-miami-cuban-bracelet.png`

The application will not invent replacement imagery for missing jewelry files. Missing source files should be added here so the public site and admin registry show the exact Campbell & Co. product visuals.
